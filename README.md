# style-guide-project

README — основной документ, с которого начинается знакомство с программным проектом.

Рекомендуемая структура:

1. Название проекта.
2. Краткое описание.
3. Основные возможности.
4. Требования к окружению.
5. Установка.
6. Запуск.
7. Использование.
8. Дополнительная информация.

### Пример структуры

```text
# Название проекта
## Описание
## Основные возможности
## Требования
## Установка
## Запуск
## Использование
```

Необязательные разделы допускается исключать, если они не относятся к проекту.

## Инструкция по установке

Инструкция должна содержать:

1. Назначение документа.
2. Предварительные требования.
3. Последовательность установки.
4. Настройку окружения.
5. Запуск приложения.
6. Проверку результата.
7. Решение распространённых проблем.

Каждый шаг должен содержать конкретное действие.

Команды оформляйте отдельными блоками кода с указанием языка.

## Общие требования к шаблонам

- Используйте понятные названия разделов.
- Не оставляйте незаполненные поля шаблона в опубликованной документации.
- Указывайте версии зависимостей, если они влияют на выполнение инструкции.
- Проверяйте актуальность команд и ссылок.
- Обновляйте шаблоны при изменении требований к документации.
