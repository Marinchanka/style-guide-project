# Работа с Markdown

Markdown используется для создания и редактирования технической документации в репозитории GitHub.

## Именование файлов

1. Используйте расширение `.md`.
2. Записывайте имена файлов латинскими буквами в нижнем регистре.
3. Разделяйте слова дефисом.
4. Выбирайте имена, отражающие содержание документа.

**Рекомендуется:** `installation-guide.md`

**Не рекомендуется:** `New Document 1.md`

## Заголовки

Используйте заголовки с символом `#`.

```markdown
# Название документа

## Основной раздел

### Подраздел
```

Отделяйте заголовки от текста пустыми строками.

## Форматирование

- Полужирный текст: `**текст**`.
- Курсив: `*текст*`.
- Встроенный код: обратные кавычки вокруг команды или имени файла.

## Блоки кода

Для многострочных примеров используйте ограждённые блоки кода с указанием языка.

Пример команды:

```bash
pip install -r requirements.txt
```

Пример Python:

```python
def greet(name: str) -> str:
    return f"Hello, {name}"
```

## Ссылки

Для внутренних ссылок используйте относительные пути.

```markdown
[Инструкция по установке](installation.md)
```

Для внешних ссылок указывайте понятное название ресурса.

## Изображения

Добавляйте изображения с помощью Markdown.

```markdown
![Схема архитектуры приложения](images/architecture.png)
```

Альтернативный текст должен кратко описывать содержание изображения.

## Общие требования

- Используйте пустые строки между логическими блоками.
- Не добавляйте лишние пробелы в конце строк.
- Не применяйте HTML, если достаточно возможностей Markdown.
- Завершайте каждый Markdown-файл одним символом перевода строки. Это означает, что после последней строки файла должен быть перевод строки, но не несколько пустых строк.
- Проверяйте корректность отображения документа перед публикацией.
