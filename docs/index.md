
# Руководство по стилю технической документации

Добро пожаловать в руководство по стилю технической документации программных проектов.

## Назначение

Стайлгайд устанавливает единые требования к написанию,
структуре и оформлению технической документации,
размещаемой в репозиториях GitHub.

Руководство предназначено для разработчиков и других
участников команды, которые создают и поддерживают
документацию программных продуктов.

## Основные задачи

- Обеспечить единообразие технической документации.
- Повысить понятность и доступность материалов.
- Упростить совместное редактирование документов.
- Сократить количество ошибок оформления.
- Облегчить сопровождение документации.

## Содержание руководства

В руководстве представлены правила:

- стиля изложения;
- орфографии и пунктуации;
- оформления текста;
- использования Markdown;
- подготовки типовых документов;
- применения технической терминологии.

Также представлены примеры документов, созданных
с использованием разработанных правил.

## Технологии

Для разработки и сопровождения документации используются:

- **Markdown** — формат написания документов.
- **MkDocs** — генератор сайта документации.
- **GitHub** — хранение файлов и совместная работа.
- **GitHub Actions** — автоматическая проверка и публикация.

## Внесение изменений

Изменения в руководство вносятся через отдельные
ветки и Pull Request.

Подробные требования к совместной работе будут
описаны в файле `CONTRIBUTING.md`.
