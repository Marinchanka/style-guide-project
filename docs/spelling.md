
# Орфография и пунктуация

При написании технической документации соблюдайте нормы русского языка и единые правила записи терминов, сокращений и специальных обозначений.

## Основные правила

1. Соблюдайте правила русской орфографии и пунктуации.
2. Используйте кавычки «ёлочки» для названий элементов интерфейса и цитат.
3. Используйте букву «ё», если её отсутствие может привести к неоднозначности.
4. Расшифровывайте специальные сокращения при первом упоминании.
5. Сохраняйте оригинальное написание названий технологий и продуктов.
6. Для дат в обычном тексте используйте формат ДД.ММ.ГГГГ.
7. Время указывайте в 24-часовом формате ЧЧ:ММ.
8. Используйте одинаковое написание терминов во всей документации.

## Примеры

### Названия технологий

**Не рекомендуется:**

> Запустите докер и откройте гитхаб репозиторий.

**Рекомендуется:**

> Запустите Docker и откройте репозиторий на GitHub.

### Даты и время

**Рекомендуется:**

> Обновление запланировано на 15.10.2026 в 14:30 (UTC+3).

В машинных форматах и API допускается использовать формат ISO 8601, если этого требует спецификация.

### Сокращения

**Рекомендуется:**

> Для взаимодействия с сервисом используется программный интерфейс приложения (API).

После первого упоминания допускается использовать сокращение API.
