
# Оформление текста

Единое оформление документов облегчает чтение, поиск информации и редактирование документации.

## Заголовки

1. Используйте один заголовок первого уровня (`#`) на документ.
2. Соблюдайте последовательную иерархию заголовков.
3. Не пропускайте уровни заголовков.
4. Делайте названия разделов краткими и информативными.

## Списки

Используйте маркированные списки для равнозначных элементов.

Используйте нумерованные списки для последовательности действий.

**Не рекомендуется:**

> Перейдите в каталог проекта, установите зависимости и запустите сервер.

**Рекомендуется:**

1. Перейдите в каталог проекта.
2. Установите зависимости.
3. Запустите сервер.

## Таблицы

Используйте таблицы для сравнения параметров и представления структурированных данных.

| Параметр | Назначение |
| --- | --- |
| `host` | Адрес сервера |
| `port` | Порт подключения |
| `debug` | Режим отладки |

Не используйте таблицы исключительно для визуального расположения текста.

## Выделение текста

- **Полужирный текст** — названия элементов интерфейса и важные обозначения.
- `Моноширинный текст` — команды, имена файлов, переменные и пути.
- *Курсив* — дополнительное смысловое выделение при необходимости.

Не используйте избыточное форматирование.

## Ссылки

Текст ссылки должен описывать её назначение.

**Не рекомендуется:**

> Для установки перейдите [сюда](https://www.python.org/downloads/).

**Рекомендуется:**

> Загрузите Python с [официального сайта](https://www.python.org/downloads/).
