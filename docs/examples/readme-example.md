
# TaskFlow API

TaskFlow API — учебный пример REST API для управления задачами.
Документ демонстрирует применение правил стайлгайда
к оформлению README программного проекта.

## Основные возможности

- Создание задач.
- Получение списка задач.
- Изменение информации о задаче.
- Удаление задач.

## Требования

Для запуска предполагаемого приложения необходимы:

- Python 3.12 или новее.
- Менеджер пакетов pip.
- Установленные зависимости проекта.

## Установка

1. Клонируйте репозиторий проекта.
2. Перейдите в каталог приложения.
3. Создайте виртуальное окружение.
4. Установите зависимости.

Подробная последовательность действий приведена
в [инструкции по установке](installation-example.md).

## Запуск

В учебном примере предполагается запуск приложения
с помощью сервера Uvicorn:

```bash
uvicorn main:app --reload
```

Команда приведена для демонстрации оформления.
Она предполагает наличие модуля `main.py` с объектом `app`.

## Использование

После запуска приложения документация API может быть
доступна по адресу `http://127.0.0.1:8000/docs`,
если используется стандартная конфигурация FastAPI.
